{{/* Click-to-play YouTube embed, overriding Hugo's built-in shortcode. The built-in one loads YouTube's iframe as the page loads. That costs several hundred KB of script on every page with a video, and behind the GFW the request never finishes, so the page never finishes loading. This renders a button instead and only swaps in the player when it is clicked. In mainland China, where YouTube is blocked, a video with a Bilibili mirror (data/video.yaml, or bilibili="BV…" here) plays from Bilibili instead, and one without shows a note in place of the player. Usage: {{< youtube CF0w2wBssMU >}} or {{< youtube id="CF0w2wBssMU" title="…" >}} */}} {{ $id := or (.Get "id") (.Get 0) }} {{ $title := or (.Get "title") .Page.Title }} {{ $label := printf "%s: %s" (T "yt_play") $title }} {{ $bilibili := .Get "bilibili" }} {{ if not $bilibili }}{{ with hugo.Data.video.bilibili }}{{ $bilibili = index . $id }}{{ end }}{{ end }}
