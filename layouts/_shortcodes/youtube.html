{{/* Click-to-play YouTube embed, overriding Hugo's built-in shortcode. The built-in one loads YouTube's iframe as the page loads. That costs several hundred KB of script on every page with a video, and behind the GFW the request never finishes, so the page never finishes loading. This renders a button instead and only swaps in the player when it is clicked. Where YouTube can't be reached (mainland China, or any network that blocks it), a video with our own copy (static/videos/yt-.mp4, H.264 under 19 MB so jsDelivr serves it) plays that instead, and one without shows a note in place of the player. A poster at static/images/yt--poster.webp replaces YouTube's thumbnail everywhere, since its image host is blocked in China too. Usage: {{< youtube CF0w2wBssMU >}} or {{< youtube id="CF0w2wBssMU" title="…" >}} */}} {{ $id := or (.Get "id") (.Get 0) }} {{ $title := or (.Get "title") .Page.Title }} {{ $label := printf "%s: %s" (T "yt_play") $title }} {{ $video := printf "/static/videos/yt-%s.mp4" $id }} {{ $hasVideo := fileExists (strings.TrimPrefix "/" $video) }} {{ $poster := printf "/static/images/yt-%s-poster.webp" $id }} {{ $thumb := printf "https://i.ytimg.com/vi/%s/hqdefault.jpg" $id }} {{ $thumbSize := dict "width" 480 "height" 360 }} {{ if fileExists (strings.TrimPrefix "/" $poster) }} {{ $thumb = partial "jsdelivr-url.html" $poster }} {{ $thumbSize = partial "image-size.html" $poster | default $thumbSize }} {{ end }}
