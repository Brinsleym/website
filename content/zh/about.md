      <h1>约克大学</h1>
      <p>
        林泽于2025年夏季以一等荣誉学位毕业。在大学期间，他的最终年毕业论文项目涉及创作一组新作品的影视配乐作品集。（<a href="https://brinsleymorrison.com/blog/final-year-dissertation-project/" target="_blank">了解更多详情请点击这里</a>）。在约克学习期间，林泽还与<a href="york.ac.uk" target="_blank">约克大学交响乐团</a>合作演出，与<a href="york.ac.uk" target="_blank">The 24</a>合唱团演唱，以及为<a href="york.ac.uk" target="_blank">The Chimera Ensemble</a>委约音乐并与其合作演出。
      </p>
      <p>
        2023年，林泽在<a href="https://www.yorkoratory.com/st-wilfrids" target="_blank">约克圣殿（圣威尔弗里德）</a>担任合唱学者，在四声部独唱合唱团中演唱，每周演出两场服务，并被<a href="https://www.york.ac.uk/arts-creative-technologies/study/funding/choral-scholarship/" target ="_blank">约克大学授予合唱奖学金</a>。
      </p>
      <h1>早期职业生涯</h1>
      <p>
        林泽 在 <b>赫里福德大教堂</b> 开始了他的音乐生涯，作为合唱团成员唱了三年（2015-2017）。在那段时间里，他每年都演唱巴赫的《受难曲》和《清唱剧》，以及许多其他大型音乐作品。在赫里福德大教堂合唱团期间，他曾在 <b>白金汉宫</b> 演出，在 <b>BBC第三电台</b> 播出，并且曾与合唱团一起 <b>美国巡演</b> 一周。<br>
        在赫里福德大教堂，林泽每周唱21小时，并在每周6天的服务中表演音乐。尽管工作量对这么年轻的他来说非常辛苦，但林泽感到极大的满足，他对音乐的热爱和他的声乐技巧也迅速得到了发展。
      </p>

      <h1>切塔姆音乐学校</h1>
      <p>
       林泽继续在 <a href="https://chethamsschoolofmusic.com" target="_blank">切塔姆音乐学校</a> 完成六年级的学习，期间他曾向 <a href="https://sites.google.com/site/douglasmasoncomposer" target="_blank">道格拉斯·梅森</a> 和 <a href="http://www.jeremypike.com/" target="_blank">杰里米·派克</a> 学习作曲，接受 <a href="https://web.archive.org/web/20110109012615/http://www.northernvoices.co.uk/html/helen_francis.html" target="_blank">海伦·弗朗西斯</a> 和 <a href="https://g.co/kgs/U5eVBw" target="_blank">马库斯·法恩斯沃思</a> 的声乐指导。
       林泽还学习了小提琴和钢琴，并在完成学业前获得了这三种乐器的 ABRSM 8级证书。他参与了爵士乐队、管弦乐队，甚至成立了一个四重唱合唱团——他在其中演唱，每周排练并参与多次演出。林泽还参加了其他由学生主办的合唱团，并且在切塔姆的室内合唱团和现代合唱团中演唱。
      </p>

       林泽 曾多次 <b>与BBC合作</b>，包括两次作为合唱团成员在 <b>BBC第三电台</b> 表演，第一次是赫里福德大教堂的 <a href="https://www.bbc.co.uk/programmes/b076b7td" target="_blank">复活节直播</a>，第二次是在 <a href="https://www.bbc.co.uk/programmes/b063dlsc" target="_blank">三大教堂节庆服务</a> 中的演出。林泽还曾在 BBC 青少年作曲家 30 秒作曲挑战赛中成为 <b>半决赛选手</b>。在切塔姆音乐学校的最后一年，林泽 <b>与BBC交响乐团</b> 作为独唱歌手合作演出，并与切塔姆的室内合唱团一起演唱海顿的《和声弥撒》，该演出在 <a href="https://www.bridgewater-hall.co.uk/" target="_blank">布里奇沃特音乐厅</a>举行，并被录音后 <a href="https://www.bbc.co.uk/events/e4qmzc" target="_blank">在BBC第三电台播出</a>。
