        <h2>はじめに</h2>
        <p>ようこそ<strong>brinsleymorrison.com</strong>へ。本プライバシーポリシーにおける「私たち」、「私たちの」、「当サイト」とは<strong>brinsleymorrison.com</strong>を指します。私たちはあなたのプライバシーを大切にし、あなたの個人情報を保護することにコミットしています。本プライバシーポリシーは、当サイトを訪問する際に私たちがどのように情報を収集、使用、保護するかについて説明します。</p>
        <p>当サイトをご利用いただくことで、本プライバシーポリシーに従い情報を収集し使用することに同意したことになります。私たちがあなたの個人データをどのように取り扱うかについて質問や懸念がある場合は、<a href="mailto:contact@brinsleymorrison.com">contact@brinsleymorrison.com</a>までご連絡ください。</p>
        
        <h2>1. 収集する情報</h2>
        <p>当サイトで収集する情報は以下の通りです：</p>
        <ul>
            <li><strong>お問い合わせフォーム:</strong> お問い合わせフォームに入力された情報を収集します。収集する個人情報は以下の通りです：
                <ul>
                    <li><strong>氏名:</strong> あなたを識別するため。</li>
                    <li><strong>メールアドレス:</strong> お問い合わせに返答するため。</li>
                    <li><strong>メッセージ:</strong> フォームを通じて送信された内容。</li>
                </ul>
            </li>
        </ul>
        <p>この情報は<strong>Formspree</strong>というサードパーティのサービスを通じて処理されます。Formspreeは、メッセージの送信とコミュニケーションのためだけにデータを保存します。</p>
        
        <h2>2. 情報の使用方法</h2>
        <p>お問い合わせフォームで収集した個人情報は、以下の目的でのみ使用されます：</p>
        <ul>
            <li>お問い合わせフォームを通じて送信されたご質問やリクエストに返信するため。</li>
        </ul>
        <p>このデータはマーケティング目的で使用することはなく、Formspreeを通じて処理される以外の第三者と共有することはありません。</p>
        
        <h2>3. クッキーおよび追跡技術</h2>
        <p>当サイトでは、追跡技術（分析や広告用のクッキーなど）は使用していません。設定される可能性のあるクッキーは、フォーム送信時のセッション管理など、基本的な機能に必要なもののみです。これらのクッキーは必須であり、個人情報を収集することはありません。</p>
        <p>ユーザーの設定情報を保存することはなく、他のサイトやサービスを通じてユーザーを追跡することもありません。</p>
        
        <h2>4. データの保存およびセキュリティ</h2>
        <p>当サイトは、<strong>IONOS</strong>というサードパーティのホスティングプロバイダーによって提供される<strong>VPSサーバー</strong>でホストされています。フォームを通じて送信された個人データはFormspreeによって処理されますが、当サイトのサーバーにはユーザーデータは保存していません。Formspreeには独自のプライバシーおよびデータ保護ポリシーがありますので、そのウェブサイトで確認できます。</p>
        <p>私たちは、データ送信時にブラウザとサーバー間で情報を暗号化する<strong>HTTPS</strong>を使用するなど、情報を保護するために合理的な措置を講じています。</p>
        
        <h2>5. データの保持期間</h2>
        <p>収集した個人データは、その収集目的を達成するために必要な期間のみ保持されます。お問い合わせフォームの場合、ご質問に対応し、さらにコミュニケーションを行うために必要な期間のみデータを保持します。コミュニケーションが完了した後は、法律上の理由で保持が必要でない限り、データはシステムから削除されます。</p>
        
        <h2>6. あなたの権利</h2>
        <p>ユーザーとして、適用されるデータ保護法（例えば、<strong>一般データ保護規則（GDPR）</strong>）に基づき、以下の権利があります：</p>
        <ul>
            <li><strong>アクセス権:</strong> 当サイトが保持しているあなたの個人データにアクセスすることができます。</li>
            <li><strong>訂正権:</strong> 当サイトが保持している不正確または不完全な個人データを訂正するよう要求できます。</li>
            <li><strong>削除権:</strong> あなたの個人データを削除するよう要求できます。</li>
            <li><strong>同意の撤回権:</strong> お問い合わせフォームを通じて提供された個人データに対する同意をいつでも撤回することができます。同意を撤回した場合、当サイトはその目的で個人データの処理を停止します。</li>
        </ul>
        <p>これらの権利を行使するには、<a href="mailto:contact@brinsleymorrison.com">contact@brinsleymorrison.com</a>までご連絡ください。</p>
        
        <h2>7. 子供のプライバシー</h2>
        <p>当サイトは13歳未満の子供を対象としていません。私たちは子供の個人データを意図的に収集することはありません。万が一、13歳未満の子供から個人データを収集したことが判明した場合、その情報は速やかに削除します。</p>
        
        <h2>8. サードパーティのサービス</h2>
        <p>お問い合わせフォームの送信処理には<strong>Formspree</strong>を使用しています。Formspreeはフォームデータを処理し、私たちに送信します。Formspreeがどのようにデータを取り扱うかについては、Formspreeのプライバシーポリシーをご確認ください。</p>
        <p>当サイトは、フォーム送信データを保存するサードパーティのホスティングプロバイダー<strong>IONOS</strong>を利用しています。IONOSのプライバシーポリシーは、そのウェブサイトで確認できます。</p>
        <p>私たちは、個人データを収集または保存する他のサードパーティサービスを使用していません。</p>
        
        <h2>9. 本プライバシーポリシーの変更</h2>
        <p>本プライバシーポリシーは、時折更新されることがあります。重要な変更がある場合は、このページに更新されたバージョンを掲示して通知いたします。「発効日」の欄に記載された日付は、本プライバシーポリシーの最新の発効日を示します。</p>
